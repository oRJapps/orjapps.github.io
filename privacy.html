プライバシーポリシー

このページは、「お絵かき合体」（https://orjapps.github.io/ と、その中のページ。以下「このサイト」）での、情報のあつかいを説明します。

1. このサイトが受け取る情報

  • なまえ（ニックネーム）：ゲームの画面に出すために使います。お使いのブラウザの中に保存されます。部屋に入ると、同じ部屋の人に送られます。本名は入れないでください。
  • 部屋の情報：部屋のカギ（4けたの数字）、難易度、人数、状態を、通信サービス（Supabase）に保存します。部屋は、使われなくなると消えます。
  • 描いた絵と、入れたお題・答え：同じ部屋の人に送るだけで、サーバーには保存しません。
  • 遊んだ記録：出たお題や自己ベストの点数を、お使いのブラウザの中に保存します。サーバーには送りません。

このサイトは、メールアドレス、住所、電話番号などを集めません。会員登録もありません。

2. 広告について

このサイトは、第三者配信の広告サービス「Google AdSense」を使います。Google などの第三者配信事業者は、Cookie を使って、利用者がこのサイトやほかのサイトを前に見たときの情報にもとづいて、広告を出すことがあります。

  • Google が広告 Cookie を使うことで、Google とそのパートナーは、利用者がこのサイトやほかのサイトを見た情報にもとづいて、利用者に合った広告を出せます。
  • 利用者は、広告設定で、パーソナライズ広告を止めることができます。
  • Google が情報をどう使うかは、Google のポリシーと規約をご覧ください。

このサイトは、広告配信サービス「忍者AdMax」（株式会社サムライファクトリー）も使います。忍者AdMax は、広告を出すために Cookie を使い、このサイトやほかのサイトへのアクセスの情報を集めることがあります。この情報から、個人が特定されることはありません。くわしい内容と、情報の利用を止める方法は、忍者ツールズのプライバシーポリシーをご覧ください。

3. 外部のサービス

  • GitHub Pages：このサイトを置いているサービスです。ページを開くと、アクセスの記録（IPアドレスなど）が GitHub に残ることがあります。
  • Supabase：部屋を作ることと、部屋の中の通信に使います。
  • Google Fonts：文字の形（フォント）を読みこむために使います。
  • Google AdSense：広告を出すために使います。
  • 忍者AdMax：広告を出すために使います。

4. お子さまの利用について

このサイトは、お子さまも遊べるゲームです。なまえのらんに、本名や学校名などを入れないよう、保護者の方から声をかけてください。

5. このポリシーの変更

内容を変えたときは、このページを書きかえます。
